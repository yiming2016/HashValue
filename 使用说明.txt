HashValue 哈希提取工具（Windows x64 便携版）
============================================

用途：把加密文件（zip/7z/rar/Office/PDF 等）转换成 hashcat 可直接使用的哈希文件。

运行：
  1. 双击 HashValue.exe。
  2. 首次使用：点击右下角“选择…”，指定 john-packages 解压后
     的 run 目录（包含 john.exe 和 2john 脚本）。
     下载：https://github.com/openwall/john-packages/releases
  3. 将加密文件拖入窗口，确认格式与 hashcat 模式号。
  4. 点击“提取哈希”，复制结果或使用输出的 .txt 文件。
  5. 破解：hashcat -m <模式号> 输出文件.txt 密码字典.txt

说明：
  - 部分格式（.py/.pl 脚本）需要安装 Python 或 Perl。
  - 程序为便携版，配置保存在同目录 HashValue.ini；
    删除整个文件夹即可卸载。

源码：https://github.com/yiming2016/HashValue
