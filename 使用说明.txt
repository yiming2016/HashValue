HashValue 哈希提取工具（Windows x64 便携版）
============================================

用途：把加密文件（zip/7z/rar/Office/PDF 等）转换成 hashcat 可直接使用的哈希文件。

运行：
  1. 双击 HashValue.exe。
  2. 程序已内置 JtR 的 run 目录，独立运行，无需额外配置；
     如需更换，可点击右下角“选择…”重新指定。
  3. 将加密文件拖入窗口，确认类别/格式与 hashcat 模式号。
  4. 点击“提取哈希”，复制结果或使用输出的 .txt 文件。
  5. 破解：hashcat -m <模式号> 输出文件.txt 密码字典.txt

更新 JtR：
  - 下载新版 john-packages，删除并整体替换本目录下的 run 文件夹；
  - 重启程序后点击“扫描新格式”，新版新增的格式会出现在“新发现”类别。
    扫描结果会自动记住，无需每次扫描。

说明：
  - 部分格式（.py/.pl 脚本，如 7z2john、pdf2john）需要系统安装 Python 或 Perl；
    其余（zip、rar 等自带 exe 的格式）开箱即用。
  - 程序为便携版，配置保存在同目录 HashValue.ini；
    删除整个文件夹即可卸载。
